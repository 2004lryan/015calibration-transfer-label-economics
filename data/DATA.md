# Datasets — sources, licenses, and availability

This repository ships **data cards only** (see [`../docs/`](../docs/)), never
spectra. Obtain each dataset from its official source below, respecting its own
license, and place it under `05data/<id>/` as described in the main README.
SHA-256 checksums are the first 16 hex characters of the raw source file for the
public datasets and of the cleaned per-year table for the apple data, and match the
values reported in the manuscript (Supplementary Table S8).

Tasks are ordered domain pairs × label properties. By drift type: instrument 30,
origin/year 72, season 12, laboratory 12. By modality: NIR 114, MIR 12. The
registry is regenerated by `02code/61_benchmark_datasets.py`, which writes
`03data/processed/benchmarks/transfer_tasks.csv`.

## Preprocessing flow

Raw sources are read **read-only** from `05data/`; all derived arrays are written to
`03data/processed/benchmarks/*.npz`. Nothing is ever written back to the source
tree. Preprocessing is standard-normal-variate (SNV) transformation. Apple pairs
within instrument A keep its 1213 channels; pairs involving instrument B use its 229
channels, matched by nearest wavelength.
